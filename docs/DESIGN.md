# 拾光：个人消息与行动工作台

## 任务与北极星

用户打开页面是为查看、判断和完成从微信消息中提炼的事项。首屏由待办列表主导，不放宣传性大标题；过滤、来源和完成动作始终相邻。视觉意图是「把嘈杂的会话整理成一页安静的行动清单」。所有会话、消息、待办、统计均来自实际 API，无演示播种、占位联系人或伪造成功反馈。

## 探索与自主选择

三个方向保留于 `docs/design-directions.html`：

- **青绿行动台（选定）**：白色工作面、灰绿外框、森林绿行动色；窄导航、纵向待办列表、独立侧边今日概览。适合每天高频读取和处理。
- **蓝色日程纸**：横向导航、日期主导的单页布局、衬线数字。适合时间计划，但无截止时间的消息待办容易退居次要。
- **紫色事务看板**：紧密卡片与多列状态布局。适合项目协作，但个人微信待办更需要快速逐项判断，多列会分散注意力。

选择第一方向是为了直接服务「看待办、回原消息、作决定」。参考品类是个人任务工具与消息收件箱；采用 Linear 一类工具的直接列表、快捷搜索、来源就近与低成本完成动作，采用 Things 一类个人工具的安静层级。保留列表与键盘基线，换掉深色开发工具语法、大面积高饱和背景、项目协作式看板和营销口号。没有参考 project4 的前端界面。

## 页面与交互

- 待办：搜索、状态、优先级、会话、今天/逾期/未来截止筛选；统计点击快速筛选；逐项完成与恢复。
- 详情：右侧抽屉保留当前清单位置，提供原始消息、附件、上下文摘要和事件记录；编辑、完成、忽略和恢复；提交携带 version，409 冲突保留输入并明确提示。
- 会话：真实 catalog 选择、关注开关、导入历史、标记已读、原始消息分页、过滤记录和单会话提炼。
- 规则：表达式、名称、说明、动作、启用状态；创建/编辑失败不关闭弹窗，删除有具体对象确认。
- 画像：Markdown 编辑与保存，自动刷新不改编辑中的内容。
- 设置：兼容 OpenAI 服务、API Key、关闭思考说明、读取节奏、探测、导出与数据库备份。Key 空输入保留已配置值，后台响应可掩码。
- 全局：Ctrl/Cmd K 搜索与跳转，↑/↓/Enter/Escape；抽屉与弹窗焦点约束、返回触发元素、标签与 aria；API 错误提示不清空表单。

## 关键状态

无数据、筛选无匹配、加载中、真实读取进度、连接失败、停止连接、模型失败、取消处理中、提交冲突均有可观察反馈。历史导入是真实同步读取，按钮显示「正在导入…」并等待结果；仅在响应后报告新增数。提炼轮次轮询真实 run 数据，完成后刷新统计和列表。自动刷新保留过滤条件、当前会话、编辑画像/设置/待办的输入。

## 三处基本动效

1. **主动作反馈**：按钮按下缩至 0.975；完成圆形勾选以 240ms 缩放出现；提交期间禁用重复执行。
2. **状态来路**：状态标签使用同一块滑动白色底板，220ms 移动；右侧待办抽屉以 300ms 从右滑入，并保留列表上下文。
3. **首次出场**：标题、统计、任务工作区依次以 50ms 间隔出场，总时长 500ms 内；重新加载不重复播放。

全部支持 `prefers-reduced-motion`，减少动态时直接呈现终态。截图位于 `artifacts/frontend/desktop.png`、`artifacts/frontend/mobile.png`、`artifacts/frontend/detail.png`；动效三帧/录屏与最终集成复核由主线程保存，本文不把源码检查当作实际视觉评分。

## 设备与验收

1440px：完整三栏工作区，关键操作与首项待办在首屏；1000px 以下概览降为横排；760px 以下导航压缩为图标；390px：58px 导航、主区保留可读宽度、表单单列、筛选不溢出、抽屉全屏、消息附件限宽。放大 200% 时自然使用窄屏规则，内容通过正常滚动访问。

验收须读取真实微信数据，不注入假聊天；检查 1440/390 两种视口、表单保存/失败后保留、保存后读回、详情原消息、分页游标、提炼状态与键盘焦点。初版独立盲审 7/10，记录在 `docs/VISUAL-REVIEW.md`；已按反馈把手机四项统计改为一行、将第一个待办从 y551 提前至 y374、提高小字与语义颜色对比。390px 首屏可完整读 4 项，五个页面均做水平溢出检查；1440/390 无浏览器脚本异常。最终复评分由主线程保存。已执行减法：移除大口号、重复解释、装饰统计趋势、来源页聊天发送入口与与当前任务无关的通知按钮；重复的说明与上下文只保留一次，长摘要可折叠，原始消息始终完整保留。

纯函数检查在 `tests/web.test.mjs`，覆盖不可信文本转义、option 上下文转义、本机附件路径边界、上海时区跨日与空/无效截止时间；无编造微信消息或数据库写入。真实 API 页面检查涉及只读路由、待办来源、快捷搜索和视口适配；保存及失败路径由主线程进行集成验证。
